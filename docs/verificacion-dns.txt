Verificación de dominio de GitHub Pages — PineappleVA
=======================================================

Instrucciones tal como las dio GitHub (recibidas el 12/09/2026):

1. Create a TXT record in your DNS configuration for the following hostname:
   _gh-PineappleVA-o.pineappleva.github.io

2. Use this code for the value of the TXT record: 9f7c8e345a
   Please note that the code will expire in 7 days.

3. Wait until your DNS configuration changes. This could take up to 72 hours
   to propagate.

Notas internas:
- El código caduca 7 días después de generarlo (entregado el 12/09/2026,
  así que apunta a caducar sobre el 19/09/2026). Si caduca, se puede
  regenerar otro desde Settings -> Pages de la organización.
- Este archivo es interno: no se enlaza desde ninguna página pública de la web.
