# pineappleva.github.io

Portafolio oficial de **Pineapple** · *Making things a little bit better* 🍍

Web estática (HTML + CSS + JS sin dependencias) que sirve como página principal de la
organización en `https://pineappleva.github.io/`.

## Características

- 🇪🇸 Contenido en **español**, traducible a cualquier idioma con **Google Translate**
  (menú «Idioma» en la cabecera y enlaces en el pie, mediante `translate.goog`).
- 🍍 Estética de la marca: fondo oscuro cálido, acento ámbar `#f5a623` y tarjetas redondeadas
  (mismo sistema de diseño que [Pineapple Games](https://pineappleva.github.io/Games/)).
- ♿ Accesible: HTML semántico, navegación por teclado, `prefers-reduced-motion` y texto alternativo.
- 📱 Responsive con menú móvil.
- 🚫 Sin frameworks, sin dependencias externas y sin cookies.

## Estructura

```
index.html              ← página única (portafolio)
assets/css/style.css    ← estilos (paleta de marca)
assets/js/main.js       ← menú móvil, idiomas y animaciones (mínimo)
assets/img/             ← logos oficiales (pineapple, School Utilities, Y)
```

## Probar en local

```bash
python3 -m http.server 8080
# → http://localhost:8080
```
